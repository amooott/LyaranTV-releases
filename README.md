# LyaranTV — versions publiées

Ce dépôt ne contient **aucun code source**. Il reçoit uniquement les versions
publiées de LyaranTV : installateur, exécutable et empreintes SHA-256.

- **Téléchargement** : onglet *Releases*.
- **Licence** : à partir de la 1.9.0, LyaranTV est distribué sous contrat
  d'utilisation final (EULA), publié sur la page d'achat. Les versions **1.8.5
  et antérieures** restent sous licence MIT.
- **Code source** : plus publié à partir de la 1.9.0.

LyaranTV est un lecteur. Ce dépôt ne distribue aucun contenu, aucune playlist,
aucun fournisseur, aucun identifiant et aucune URL de fournisseur.
